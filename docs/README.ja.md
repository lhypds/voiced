# Voiced

[English](../README.md) | [中文](README.zh-CN.md) | **日本語**

Voiced は、ローカルでリアルタイム音声認識を行うネイティブ macOS アプリです。マイクや Loopback、BlackHole の仮想デバイスなど、任意の Core Audio 入力デバイスを聞き取り、文ごとにタイムスタンプ付きで表示します。音声も文字起こしも端末の外には出ません。

## モデル

認識には WhisperKit の Core ML モデルを使います。設定で 2 つのエンジンを選べます。

| エンジン | モデル | 説明 |
| --- | --- | --- |
| 高速（デフォルト） | Whisper large-v3 Turbo（632 MB） | 応答が速く負荷が軽い。リアルタイム字幕や性能の低い Mac 向け。 |
| 高精度 | Whisper large-v3（626 MB） | 中国語・日本語・英語の精度が高い代わりに処理が遅い。 |

各モデルは初めて選択したときに Hugging Face からダウンロードされ、以降はローカルキャッシュを使います。

認識言語：自動検出、中国語、英語、日本語、韓国語、スペイン語、フランス語、ドイツ語、ポルトガル語、ロシア語。

表示言語：英語、中国語、日本語、フランス語、スペイン語、ドイツ語。初期設定ではシステムの言語に従い、対応していない場合は英語になります。

## ビルドと実行

macOS 14 以降が必要です。Apple Silicon を推奨します。

```sh
./Scripts/build-app.sh
open .build/Voiced.app
```

リポジトリ直下の `start.sh`、`stop.sh`、`restart.sh` も同じことを行い、必要に応じて再ビルドします。

`./install.sh` は `/usr/local/bin/voiced` に `voiced` コマンドをインストールします。ターミナルで `voiced` または `voiced start` がアプリを開き、`voiced stop` が終了、`voiced restart` が再起動します。`./uninstall.sh` で削除できます。アプリの Voiced メニューにも同じ「voiced コマンドをインストール」があります。

初回起動時にマイクへのアクセス許可を求められます。macOS は仮想オーディオデバイスもマイク入力として扱うため、物理マイクを使わない場合でもこの許可が必要です。

## 他のアプリの音声を取り込む

1. Loopback で仮想デバイスを作成し、対象アプリを Sources に追加します。または BlackHole をインストールし、「Audio MIDI 設定」で複数出力装置を作成します。
2. Voiced を起動し、サイドバーの「入力」でその仮想デバイスを選びます。
3. 精度を上げるには、よく使う言語を固定します。内容の言語が頻繁に切り替わる場合は「自動検出」を選びます。
4. マイクボタンで開始し、停止ボタンで終了します。

BlackHole を使っていて音声も聞きたい場合は、スピーカーと BlackHole の両方に出力する複数出力装置を使ってください。

## 設定

- 認識エンジン、認識言語、表示言語。
- 翻訳：各文を選んだ言語（表示言語と同じ 6 言語）に翻訳し、原文と同じ吹き出しに表示します。初期設定では原文がメインで、訳文はその下に小さな灰色の文字で表示されます。「メインの文字」で入れ替えられます。翻訳は macOS の翻訳フレームワークがこの Mac 上で行い（macOS 15 以降）、内容は外部に送られません。初めて使う言語では言語パックのダウンロードを求められます。初期設定ではオフ。訳文は文字起こしと一緒に保存されます。
- ウインドウを最前面に固定：他のアプリに切り替えてもウインドウを前面に表示し続けます。
- タイムスタンプ：相対時間または現在時刻。日付の表示も選べます。
- 音量しきい値：これより小さい音は無視されます。スピーカーの音をマイクで拾う場合など、小さな音源では下げてください。
- 音声フィルター：音声検出モデル（Silero VAD）で入力のどこが人の声かを判定します。BGM のように大きくても音声でない音は認識のきっかけにならず、文を引き延ばすこともなくなります。初期設定ではオフ。初めてオンにしたときに Hugging Face からモデル（約 1 MB）をダウンロードし、認識モデルと同じ場所にキャッシュします。
- 認識プレビュー：現在の設定で聞き取り、入力レベルと認識結果を表示します。本文には追加されません。しきい値の調整に便利です。
- OpenAI API キー（AI ページ）：入力すると、履歴の各記録に「要約する」操作が加わります。文字起こし全体を OpenAI に送り、要約（表示言語）を記録フォルダの `summary.txt` に書き込みます。「要約を開く」で確認できます。内容を外部に送るのは要約と AI ヒントだけで、操作したとき、またはオンにしたときだけ送られます。AI ページには要約のスイッチがあり、機能ごとに OpenAI のモデルを一覧から選べます。キーは `~/.voiced/settings.json` に保存されます。
- AI ヒント（AI ページ）：キーを入力した上でこのスイッチを入れると、新しく認識した文のうち、質問や、人名・地名、略語や型番、辞書にない語、中国語・日本語の中の欧文単語、長いカタカナ語を含むものだけを、直前の数行とともに OpenAI に送ります。日常的な文は送られません。「ウェブ検索」をオンにすると、ヒントを書く際にモデルが OpenAI の検索ツールでウェブを調べられます。応答は遅く、費用は高くなり、検索対応モデルが必要です。難しい事柄や質問を含む文があると、文字起こしの先頭、LIVE 行の上に「AI」行として短い説明や答えが表示されます。ポインタを載せている間は残り、それ以外は読み終わる頃に自動で消えます。× で先に閉じることもできます。ヒントは表示言語で書かれますが、「AI ヒントの言語」で別の言語を選べます。初期状態ではオフです。
- 認識プロンプト：人名、製品名、専門用語など、優先して認識させたい語です。「ファイルを編集」でデフォルトのテキストエディタに `~/.voiced/prompt.txt` が開くので、話す言語で 1 行に 1 語ずつ書きます。`#` で始まる行は無視されます。ファイルは認識やプレビューの開始時に読み込まれます。Whisper に厳密なキーワード一覧はなく、プロンプトはモデルをその表記に寄せるだけです。数十語までが効果的で、先頭 223 トークンが使われます。

## ディスク上のデータ

Voiced が保存するものはすべて `~/.voiced` にあります。

```
~/.voiced/
  settings.json             設定
  prompt.txt                認識プロンプト：優先して認識させたい語を 1 行に 1 つ
  history/<unix time>/      履歴 1 件につき 1 ディレクトリ。開始時刻の Unix 時間（秒）が名前
    transcript.json         文字起こしと、録音セッションごとの情報（開始・終了時刻、入力デバイス、言語、エンジン、音声ファイル名）
    <unix time>.wav         各セッションの生の音声（16 kHz モノラル 16 bit PCM）
    summary.txt             履歴で要約したときの AI 要約
```

録音セッションは開始ボタンから停止ボタンまでです。最初のセッションがディレクトリを作り、履歴から選んでから録音すると、新しいセッションの音声は自分の開始時刻の名前で同じディレクトリに追加されます。音声ファイルは録音中に書き込まれるため、アプリが突然終了しても壊れません。何も認識されなかったセッションでも音声は残ります。音声がまったく入らなかったセッションは何も残しません。履歴で記録を削除すると、ディレクトリと音声ごと削除されます。保存した音声は `VoicedSimulate` で認識エンジンに再度流せます（[Develop.md](Develop.md) 参照）。

以前のバージョンが `UserDefaults` と `~/Library/Application Support/Voiced/History/` に保存した設定と履歴は、初回起動時に `~/.voiced` へ移動されます。

## 履歴

文が確定するたびに、現在の文字起こしが `~/.voiced/history/` に自動保存されます。右上の履歴ボタンで過去の記録を一覧でき、選ぶと画面に戻ります。その状態で認識を再開すると、新しい文はその後ろに追加されます。「新規」（＋）は画面を消して新しい記録を始めるだけで、保存済みの記録は残ります。記録を削除するには一覧のゴミ箱アイコンをクリックします。
