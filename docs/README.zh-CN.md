# Voiced

[English](../README.md) | **中文** | [日本語](README.ja.md)

Voiced 是一个原生 macOS 本地实时语音识别应用。它可以监听任意 Core Audio 输入设备，包括麦克风以及 Loopback、BlackHole 虚拟设备，并按句显示带时间戳的转写内容。音频和转写内容不会离开本机。

## 模型

识别基于 WhisperKit 的 Core ML 模型。设置中提供两种识别引擎：

| 引擎 | 模型 | 说明 |
| --- | --- | --- |
| 高速（默认） | Whisper large-v3 Turbo（632 MB） | 响应更快、资源占用更低，适合实时字幕和配置较低的 Mac。 |
| 高精度 | Whisper large-v3（626 MB） | 中日英识别更准确，但响应较慢。 |

每个模型在首次选择时从 Hugging Face 下载，之后保存在本机缓存中。

识别语言：自动检测、中文、英文、日文、韩文、西班牙文、法文、德文、葡萄牙文、俄文。

界面语言：英文、中文、日文、法文、西班牙文、德文。默认跟随系统语言，系统语言不在其中时使用英文。

## 构建与运行

要求 macOS 14 或更高版本，推荐 Apple Silicon。

```sh
./Scripts/build-app.sh
open .build/Voiced.app
```

根目录的 `start.sh`、`stop.sh`、`restart.sh` 作用相同，并会在需要时自动重新构建。

`./install.sh` 会在 `/usr/local/bin/voiced` 安装 `voiced` 命令：在终端输入 `voiced` 或 `voiced start` 打开应用，`voiced stop` 退出，`voiced restart` 重新启动；`./uninstall.sh` 删除该命令。应用的 Voiced 菜单里也有同样的“安装 voiced 命令”。

首次运行需要允许麦克风访问。即使选择的是虚拟音频设备，macOS 仍会把它归类为麦克风输入，因此没有物理麦克风时也需要这项权限。

## 接入其他应用音频

1. 在 Loopback 中新建虚拟设备，把目标应用加入 Sources；或安装 BlackHole 并通过"音频 MIDI 设置"建立多输出设备。
2. 启动 Voiced，在左侧"输入"中选择对应虚拟设备。
3. 选择常用语言以提高精度；内容会频繁切换语言时选择"自动检测"。
4. 点击麦克风按钮开始，点击停止按钮结束。

使用 BlackHole 时，如果还需要从扬声器听到声音，应使用多输出设备同时路由到扬声器和 BlackHole。

## 设置

- 识别引擎、识别语言和界面语言。
- 翻译：把每句话翻译成所选语言（与界面语言相同的六种），和原文显示在同一个气泡里。默认原文为主要文字，译文在下面用较小的灰色字显示；“主要文字”可以把两者对调。翻译由 macOS 的翻译框架在本机完成（需要 macOS 15 或更高版本），内容不会离开这台电脑；首次使用某种语言时系统会提示下载语言包。默认关闭。译文会随转写一起保存。
- 窗口置顶：切换到其他应用时窗口仍保持在最前面。
- 时间戳：相对时间或当前时间，可选显示日期。
- 能量阈值：低于此值的声音不会识别。外放经麦克风拾取等较小的声源需要调低。
- 人声过滤：用语音检测模型（Silero VAD）判断输入里哪些是人声，背景音乐等响但不是语音的声音不再触发识别，也不会拖住句子不结束。默认关闭。首次开启时从 Hugging Face 下载模型（约 1 MB），与识别模型缓存在一起。
- 识别预览：用当前设置试听，显示输入电平和识别文本，不会写入正文。适合用来调整阈值。
- OpenAI API 密钥（AI 页）：填写后，历史记录里的每条记录都多出“生成摘要”操作。它把整段转写发送给 OpenAI，并把摘要（使用界面语言）写入该记录文件夹下的 `summary.txt`，“打开摘要”可以查看。摘要和 AI 提示是仅有的两个会把内容发出本机的功能，且只在点击或开启时发送。AI 页里有摘要的开关，两个功能可以各自从列表里选择 OpenAI 模型。密钥保存在 `~/.voiced/settings.json`。
- AI 提示（AI 页）：填写密钥后打开此开关，新识别的句子里，只有看起来值得一问的才会连同前几句一起发送给 OpenAI：提了问题，或含有人名地名、缩写或型号、拼写检查不认识的词、中日文里夹着的英文词、较长的片假名词。日常的句子不会离开本机。打开「联网搜索」后，模型在写提示时可以通过 OpenAI 的搜索工具上网查证；响应更慢、费用更高，且需要支持搜索的模型。当一句话提到生僻事物或提出问题时，转写列表顶部、LIVE 行上方会出现一行标为「AI」的提示，给出简短的解释或回答。鼠标放在气泡上时它会一直停留，否则在读完所需的时间之后自动消失，点 × 可以提前关闭。提示默认用界面语言书写，可在「AI 提示语言」里改成其他语言。默认关闭。
- 识别提示词：希望识别器优先采用的词，比如容易识别错的人名、产品名、术语。点“编辑文件”会用默认文本编辑器打开 `~/.voiced/prompt.txt`，每行写一个词，用你说话的语言。以 `#` 开头的行会被忽略。文件在每次开始识别或预览时读取。Whisper 没有硬性的关键词表，提示词只是让模型倾向于这些写法；几十个词以内效果最好，只取前 223 个 token。

## 磁盘上的数据

Voiced 保存的所有内容都在 `~/.voiced` 下：

```
~/.voiced/
  settings.json             设定
  prompt.txt                识别提示词：希望优先识别的词，每行一个
  history/<unix time>/      每条历史记录一个目录，以开始时刻的 Unix 时间（秒）命名
    transcript.json         转写内容，以及每次录音会话一条记录：开始/结束时间、输入设备、语言、引擎、音频文件名
    <unix time>.wav         每次录音会话的原始音频（16 kHz 单声道 16 位 PCM）
    summary.txt             在历史记录里生成过的 AI 摘要
```

一次录音会话从点击开始到点击停止。第一次录音会建立记录目录；先在历史记录里选中一条再录音，新会话的音频会以自己的开始时刻命名，追加到同一目录。音频文件在录音过程中边录边写，即使应用意外退出也是完整的。没识别出任何句子的会话仍会保留音频；完全没有采到音频的会话不会留下任何东西。在历史记录里删除一条记录会连同目录和音频一起删除。保存的录音可以用 `VoicedSimulate` 重新喂给识别器（见 [Develop.md](Develop.md)）。

旧版本保存在 `UserDefaults` 和 `~/Library/Application Support/Voiced/History/` 里的设定和历史记录会在首次启动时自动挪到 `~/.voiced`。

## 历史记录

每次有句子提交时，当前转写会自动保存到 `~/.voiced/history/`。点击右上角的历史记录按钮可以选择一条旧记录放回屏幕，再次开始识别时新句子会追加在它后面。"新建"（加号）只清除屏幕并开始一条新记录，不删除已保存的记录；要删除记录在列表中点击垃圾桶图标。
