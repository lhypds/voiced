# macOS / iOS 功能核对

两端共用 `VoicedCore` 的业务函数；iOS 的入口已补齐到原生设置、转写和历史界面。此表区分“已接入功能”和“平台/当前实现差异”，不把仅存在于共享库、却无法从界面操作的函数算作完成。

| 功能 | macOS | iOS |
| --- | --- | --- |
| 四种 Whisper 模型、首次下载、本地缓存 | 支持 | 支持，同一模型加载函数 |
| 实时转写、分句、标点、去重、静音提交 | 支持 | 支持，同一识别循环和提交规则 |
| 固定语言 / 自动检测 / 自动检测语言范围 | 支持 | 支持 |
| 识别提示词 | 通过编辑文件 | 在设置 → 识别中编辑；相同解析和 223 token 限制 |
| 能量阈值、识别预览 | 支持 | 支持；预览不存历史/录音，不发送 AI 请求 |
| 麦克风和外接音频输入选择 | 任意 Core Audio 输入 | 系统 `availableInputs` 提供的输入 |
| 原始输入和降噪后的音量表 | 支持 | 设置 → 音频输入；共用电平计算函数 |
| 噪声校准、自动设置阈值、频谱降噪 | 支持 | 支持，共用校准和降噪函数 |
| Silero VAD 人声过滤、模型下载 | 支持 | 支持 |
| 时间戳格式、日期、点击复制或回放 | 支持 | 支持；识别时点击始终复制 |
| 本地历史、删除、继续追加录音 | 支持 | 支持；继续录音追加到原记录和音频 |
| 保存 WAV、从句子时间点播放、播放高亮 | 支持 | 支持，同一录音和播放服务 |
| 导出文字、录音、JSON、摘要 | 复制 / Finder / 编辑器 | 系统分享菜单 |
| 翻译开关、语言规则、原文/译文主次 | macOS 15+ | iOS 18+；相同 Apple 翻译服务 |
| 朗读新译文、语音选择、试听、防回声 | 支持 | 支持；朗读时屏蔽识别输入 |
| OpenAI API 密钥、模型列表、自定义模型名 | 支持 | 设置 → AI |
| AI 提示独立开关和模型、提示语言 | 支持 | 支持 |
| AI 提示联网搜索 | 支持 | 支持；同一 Responses 请求实现，需模型支持 |
| 本地判断是否值得询问、上下文、主题去重 | 支持 | 支持；共用 `TranscriptAI` 和 `HintTrigger` |
| 提示关闭、到时消失、延长停留 | 悬停延长 | 轻点固定 / 取消固定 |
| 关闭功能/切换记录后丢弃迟到的 AI 回答 | 支持 | 支持；同一请求生命周期实现 |
| 历史 AI 摘要开关、独立模型、生成、查看 | 支持 | 支持；摘要使用界面语言 |
| 摘要持久化、错误显示、删除记录取消请求 | 支持 | 支持；避免迟到回答重新创建已删除记录 |
| 六种界面语言 | 支持 | 英/中/日/法/西/德，原生字符串目录 |
| 重置偏好 | 支持 | 支持；不删历史、录音或模型 |

## 保留的差异

- iOS 17 仍可录音、识别和使用 AI；翻译需要 iOS 18+，低版本显示不可用说明。
- iOS 只能使用系统允许的音频输入，无法通过 Mac 的 Loopback / BlackHole 捕捉任意其他应用音频。
- iOS 当前仍采用**前台实时识别**：来电或进入后台时结束录音并保存已采集音频。这里是当前版本的实现边界，并非声称 iOS 不允许后台录音。Apple 的 [录音类别说明](https://developer.apple.com/documentation/avfaudio/avaudiosession/category-swift.struct/record)介绍了后台录音所需的音频模式；长时间后台识别及模型计算仍需单独做真机生命周期与耗电验证。
- iOS 不提供 Mac 的窗口置顶、Finder 打开目录或安装 `voiced` 命令；分别采用原生导航、分享菜单等操作。
- iOS 不在后台批量预编译所有模型，以减少手机的内存、发热和电量开销。
- 两端共用数据格式，但不自动同步设备上的文件。

## 验证范围

- `swift test`：共享算法、设置/历史迁移、AI 请求与取消边界、音频适配器等；不调用真实 OpenAI API。
- `iOS/VoicedUITests/FeatureParityUITests.swift`：真实模拟器交互，覆盖 AI 设置、提示显示和关闭、历史摘要生成/打开、翻译规则与显示、语音入口、语言切换、提示词/预览入口及 WAV 回放。
- UI 测试使用独立的临时目录和模拟 AI/翻译服务，不读取实际密钥、不改动用户历史、不下载模型、不启动麦克风。Debug 模式下仅显式 `--ui-testing` 参数启用这些测试数据；Release 不含测试实现。
- iPhone 设备 SDK 构建用于检查真机目标编译。真实麦克风/蓝牙路由、模型速度、语言包下载和付费 API 响应仍需要在自己的设备和账户上确认；模拟服务测试不能证明这些外部条件可用。

本次验证（2026-10-26）：202 项共享/平台测试、8 项模拟器界面测试全部通过；macOS Release 构建、已连接 iPhone 的签名构建通过。未覆盖安装手机中的应用；真实麦克风、语言包和付费 API 尚未做真机端到端实测。
